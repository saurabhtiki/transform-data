# Transform Data
Reusable Django add-on: upload data, transform it step by step, download Excel / JSON. Shared rules: `../CLAUDE.md`.
Scope: `docs/project.md`. Current plan: `docs/plan.md`. Loading + formulas live in `../data-core` (shared with My Insights).
`transform_data/engine` is ported from the Streamlit prototype; keep it Django-free.
